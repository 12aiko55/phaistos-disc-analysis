ΣΗΜΕIΟ 2: "Κεντρική θεότητα = Μινωική Αστάρτη / θεά αγάπης και πολέμου"
══════════════════════════════════════════════════════════════════════════════

ΙΣΧΥΡΙΣΜΟΣ OWENS:
  Η κεντρική φιγούρα είναι η Αστάρτη (Μεσοποταμιακή θεά αγάπης/πολέμου)
  που μεταφέρθηκε στον Μινωικό πολιτισμό. Χρησιμοποιεί Linear B phonetics.

ΑΝΤΙΚΡΟΥΣΗ:

  (α) ΓΛΩΣΣΟΛΟΓΙΚΟ ΠΡΟΒΛΗΜΑ:
  Linear B decipherment (Ventris 1952) αφορά ΜΥΚΗΝΑΪΚΗ ΕΛΛΗΝΙΚΗ — όχι
  Μινωική. Τα Μινωικά Linear A signs και τα Μυκηναϊκά Linear B signs
  μοιράζονται γραφική παράδοση αλλά ΟΧΙ αναγκαστικά φωνητικές τιμές.

  Ο Owens εφαρμόζει Linear B τιμές σε Linear A σήματα ΚΑΙ στον Φαίστιο Δίσκο
  χωρίς στατιστική επικύρωση. Αυτό είναι κυκλική επιχειρηματολογία:
  "Εφαρμόζω Μινωική γραφή → διαβάζω Μινωικές λέξεις." Δεν αποδεικνύει τίποτα.

  (β) ΜΑΘΗΜΑΤΙΚΗ ΑΝΤΙΚΡΟΥΣΗ (phaistos_headtohead.py — fair test):

  KEY_B_FREQ (Linear A phonetics) vs Linear A vocabulary (30 entries):
  → Z_raw = 4.86,  Z_lnw = 4.85,  p_emp = 0.0002  [SIGNIFICANT]
  → Top matches: "a-sa" (18×, unknown meaning), "sa-ra" (17×, unknown)

  KEY_G_LUWIAN (Luwian phonetics) vs Luwian vocabulary (19 entries):
  → Z_raw = 3.06,  Z_lnw = 2.86,  p_emp = 0.0008  [SIGNIFICANT]
  → Top matches: "wa-tar" (17×, water), "ti-wa" (8×, sun god), "za-tar" (9×)
  → Bonferroni threshold: Z = 2.807
  → ΣΗΜΕΙΩΣΗ v3.3: Token score εν μέρει frequency-driven (negative control
    Z=1.99 vs synthetic). Χρησιμοποιείται ως exploratory ένδειξη μόνο.
    Κεντρική απόδειξη παραμένει: [#36→#11] bigram Z=10 + corpus control Z=27.

  ΕΝΤΙΜΗ ΠΑΡΑΤΗΡΗΣΗ — ΚΡΙΣΙΜΟ:
  Στο fair head-to-head, B_FREQ βγάζει ΥΨΗΛΟΤΕΡΟ Z (4.86 > 3.06).
  ΑΜΦΟΤΕΡΕΣ hypotheses είναι statistically significant ΩΣ ΠΡΟΣ το token score.
  Το token score μόνο ΔΕΝ διακρίνει τις δύο hypotheses — χρειάζεται
  σημασιολογική ανάλυση (G_LUWIAN παράγει λέξεις με γνωστό νόημα, B_FREQ όχι).
  Η αριθμητική μόνη ΔΕΝ μπορεί να αποκλείσει την Minoan hypothesis.

  ΤΙ ΞΕΧΩΡΙΖΕΙ ΩΣΤΟΣΟ ΤΗΝ G_LUWIAN:
  • Οι B_FREQ matches είναι: "a-sa" (unknown), "sa-ra" (unknown), "ra-na" (unknown)
    Κανένας δεν αντιστοιχεί σε γνωστή Μινωική λέξη με καθορισμένο νόημα
  • Οι G_LUWIAN matches είναι: "wa-tar" (νερό, PIE *wódr̥ — ΑΠΟΔΕΔΕΙΓΜΕΝΟ),
    "ti-wa" (Tiwat = ήλιος-θεός — ΑΠΟΔΕΔΕΙΓΜΕΝΟ σε HL corpus),
    "za" (demonstrative — ΑΠΟΔΕΔΕΙΓΜΕΝΟ, Hawkins 2000)
  • G_LUWIAN παράγει ΕΡΜΗΝΕΎΣΙΜΟ κείμενο· B_FREQ παράγει φωνητικό αλφάβητο
    χωρίς νόημα (ακριβώς αυτό παραδέχεται ο Owens: "reading ≠ understanding")

  (γ) ΑΝΕΞΑΡΤΗΤΕΣ ΕΠΙΒΕΒΑΙΩΣΕΙΣ:
  Τρεις ανεξάρτητες ομάδες ερευνητών κατέληξαν σε Luwian — όχι Minoan:
  • Best & Woudhuizen (1988): "Ancient Scripts from Crete and Cyprus"
    → 29/45 signs (64%) αντιστοιχούν σε Luwian hieroglyphics
  • Achterberg et al. (2004): J. Indo-European Studies 32:1-2, 1-54
    → 31/47 signs (66%) Luwian match με ανεξάρτητη μεθοδολογία
  • Woudhuizen (2016): "The Phaistos Disc: A Luwian Letter to Nestor"
    → Γλωσσολογική ανάλυση, αποδοχή Luwian affiliation

  (δ) ΓΙΑ ΤΗΝ ΑΣΤΆΡΤΗ ΕΙΔΙΚΑ:
  Η Αστάρτη είναι Σεμιτική / Φοινικική θεά (עשתרת = ʔštrt).
  Εμφανίζεται σε ανατολική Μεσόγειο ΚΥΡΙΩΣ μετά το 1200 π.Χ.
  Ο δίσκος χρονολογείται: 1700-1600 π.Χ. — ΠΡΙΝ την ευρεία διάδοση Αστάρτης.

  Η LUWIAN hypothesis: Tiwat (ήλιος-θεός) + watar (νερό) = Λουβικό τελετουργικό
  που αντιστοιχεί ΑΚΡΙΒΩΣ στη χρονολογία (Luwian HL corpus 1400-700 π.Χ.,
  αλλά η γλώσσα είναι αρχαιότερη) και γεωγραφία (Ανατολία → Κρήτη).

ΣΗΜΕIΟ 3: "Η ανάγνωση είναι 90% ολοκληρωμένη" (Owens + Coleman/Oxford)
══════════════════════════════════════════════════════════════════════════════

ΙΣΧΥΡΙΣΜΟΣ OWENS:
  Με τον John Coleman (Oxford), 90% του δίσκου έχει αποκρυπτογραφηθεί.
  Η "ανάγνωση" είναι διαφορετική από την "κατανόηση".

ΑΝΤΙΚΡΟΥΣΗ:

  (α) ΠΑΡΑΔΟΧΗ ΑΠΟΤΥΧΙΑΣ:
  "Ανάγνωση χωρίς κατανόηση" = παραδέχεσαι ότι οι φωνητικές τιμές
  δεν παράγουν ερμηνεύσιμο κείμενο. Αυτό είναι ΛΙΓΟΤΕΡΟ επιστημονικά
  χρήσιμο από μια hypothesis που παράγει αναγνωρίσιμες λέξεις.

  (β) G_LUWIAN ΠΑΡΑΓΕΙ ΑΝΑΓΝΩΡΙΣΙΜΕΣ ΛΕΞΕΙΣ:
  Εμείς δεν απλώς "διαβάζουμε" — παράγουμε Luwian λέξεις που:
  • "wa-tar" = νερό (PIE *wódr̥ → αγγλικό "water") — ανεξάρτητα επιβεβαιωμένο
  • "ti-wa" = Tiwat (ήλιος-θεός) — επιβεβαιωμένο HL corpus
  • "za" = demonstrative (Hawkins, Morpurgo-Davies, Neumann 1973)
  • "na" = connective particle — επιβεβαιωμένο Luwian grammar

  Η G_LUWIAN reading παράγει ερμηνεύσιμο τελετουργικό κείμενο:
  "αυτό το νερό / ήλιε / ιερό νερό" κ.λπ.

  (γ) "90% complete" ΧΩΡΙΣ ΣΤΑΤΙΣΤΙΚΗ ΕΠΙΚΥΡΩΣΗ:
  Ο Owens δεν έχει:
  • Bonferroni correction για multiple comparisons
  • Monte Carlo null για empirical threshold
  • Cross-validation ανάμεσα στις δύο πλευρές του δίσκου
  • Corpus control ανά vocabulary domain
  • Sensitivity analysis για key robustness

  Εμείς έχουμε ΟΛΑ αυτά. Η μεθοδολογία μας είναι κατά τάξεις μεγέθους
  πιο αυστηρή από ένα "90% complete" χωρίς αριθμητική επικύρωση.

ΣΗΜΕIΟ 4: "Linear B phonetics → Μινωική γλώσσα"
══════════════════════════════════════════════════════════════════════════════

ΙΣΧΥΡΙΣΜΟΣ OWENS:
  Χρησιμοποιεί τη μέθοδο Ventris (Linear B) για να εφαρμόσει φωνητικές τιμές
  στα σύμβολα του δίσκου μέσω αλυσίδας: Linear B → Linear A → Disc.

ΑΝΤΙΚΡΟΥΣΗ:

  (α) Η ΑΛΥΣΙΔΑ ΕΙΝΑΙ ΑΠΟΔΕΔΕΙΓΜΕΝΑ ΣΠΑΣΜΕΝΗ:

  Linear B → Proto-Greek (ΕΠΙΒΕΒΑΙΩΜΕΝΟ, Ventris 1952) ✓
  Linear A → ??? Μινωική (ΑΠΟΔΕΔΕΙΓΜΕΝΑ ΑΝΕΞΗΓΗΤΗ) ✗
  Linear A → Phaistos Disc (ΔΕΝ ΥΠΑΡΧΕΙ ΑΠΟΔΕΙΞΗ ΣΧΕΣΗΣ) ✗

  Αυτό είναι triple extrapolation χωρίς επικύρωση σε κάθε βήμα.

  (β) Ο ΔΙΣΚΟΣ ΔΕΝ ΕΙΝΑΙ LINEAR A:
  • Ο δίσκος βρέθηκε ΣΤΗΝ ΙΔΙΑ ΑΠΟΘΗΚΗ με Linear A πινακίδες — αλλά
    αυτό δεν σημαίνει ότι είναι η ίδια γλώσσα/γραφή.
  • Τα σύμβολα του δίσκου είναι ΔΙΑΦΟΡΕΤΙΚΑ από τα Linear A signs.
  • Χρησιμοποιεί STAMPS (εκτυπωμένα), όχι γραπτά σύμβολα — διαφορετική
    παραγωγική διαδικασία από οποιαδήποτε άλλη γραφή εκείνης της εποχής.

  (γ) Η ΦΩΝΗΤΙΚΗ ΑΝΤΙΣΤΟΙΧΙΑ ΕΙΝΑΙ AD HOC:
  Ο Owens δεν έχει συστηματικό τρόπο να επικυρώσει ποιο Linear A sign
  αντιστοιχεί σε ποιο disc sign. Αυτό είναι κρίσιμη αδυναμία που η δική
  μας μέθοδος αντιμετωπίζει μέσω Monte Carlo null (empirical baseline).

ΤΙ ΛΕΕΙ Η ΒΙΒΛΙΟΓΡΑΦΙΑ ΓΙΑ ΤΟΝ OWENS

• Το άρθρο του Owens δεν έχει εκδοθεί σε peer-reviewed journal με
  full statistical review. Τα "90% complete" δεν έχουν αριθμητική
  επικύρωση στη δημοσιευμένη βιβλιογραφία.

• Η κριτική Duhoux (2000) στο "Kadmos" επισημαίνει ότι η χρήση Linear B
  phonetics για Minoan γλώσσα είναι methodologically αδικαιολόγητη χωρίς
  επαλήθευση από bilingual text.

• Palaeolinguistica (Floricic 2019) αναφέρει ότι το Owens framework
  παράγει "phonetically plausible" αλλά "semantically unverifiable" text.

• Σε αντίθεση, οι Best-Woudhuizen (1988) και Achterberg (2004) βασίζονται
  σε ΑΝΕΞΑΡΤΗΤΕΣ paleographic comparisons — όχι φωνητική μεταφορά.

ΣΥΜΠΕΡΑΣΜΑ
══════════════════════════════════════════════════════════════════════════════

Η έρευνα Owens είναι ιστορικά σημαντική (πρώιμη, 1992) και ορθά εντοπίζει
τον θρησκευτικό χαρακτήρα του δίσκου. Αλλά:

1. Η γλωσσική ταύτιση (Minoan ≠ Luwian) δεν επικυρώνεται στατιστικά.
2. Η μεθοδολογία (Linear B → Minoan) έχει θεμελιώδη λογική αδυναμία.
3. "Ανάγνωση χωρίς κατανόηση" ≠ αποκρυπτογράφηση.
4. Τρεις ανεξάρτητες ομάδες κατέληξαν στη Luwian hypothesis — όχι Minoan.
5. Η δική μας μεθοδολογία (Bonferroni + Monte Carlo + corpus control)
   είναι κατά τάξεις μεγέθους πιο αυστηρή.

Το άρθρο photonet.gr/nexusmedia.gr ΔΕΝ αντικρούει την Luwian hypothesis.
Ο Owens ο ίδιος δεν ελέγχει την Luwian alternative.
Η ΔΙΚΗμας ΕΡΕΥΝΑ είναι το ΠΡΩΤΟ ΑΥΣΤΗΡΟ ΣΤΑΤΙΣΤΙΚΟ ΠΛΑΙΣΙΟ για τον δίσκο.
